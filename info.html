    資訊｜氣動閥的原理？解析氣動執行器和氣動閥的關係

    Read Now
     
    部分手動閥附有氣動執行器裝配平台，可依需求選擇使用氣動執行器或手柄、手輪。
    因應使用環境、空間、流量、溫度等因素選用不同方式作動的閥門。
    以下要介紹的是以氣體來作動的*氣動執行器
    ​
    *註："Pneumatic actuators"翻譯為「氣動執行器」或「氣動驅動器」，
    但一般業界亦以「氣缸」稱之。
    閥門作動主要方式
    ​．手動(手柄、手輪)
    ​．電動執行器 
    ​．氣動執行器

    什麼是氣動閥？

    什麼是氣動閥？
    氣動閥顧名思義指的就是以氣源作為動力的控制閥，與電動閥相比，只需壓縮氣源的氣動閥因構造簡單、操作方便而廣泛使用，室外、高溫或其他環境較惡劣的場所基本上都是使用氣動閥。
    ​很多人認為氣動閥門就是一個產品或一個零組件，其實氣動閥可以拆成兩大主體：「氣缸」與「閥門」。
    ​
    氣缸的工作原理係利用壓縮空氣作為動力來源，當壓縮氣源進入到氣缸腔內時來推動氣缸活塞，根據進出氣孔的不同，活塞會往氣缸蓋兩端或者往軸心方向作直線運動，活塞作動時連動著曲臂帶動氣缸軸心使氣缸軸心作90度旋轉，氣缸軸心旋轉的同時也帶動了下方連接的閥門，進而使閥門達到啟閉、控制的效果。
    ​
    關於「閥」又有各式種類了，例如球塞閥、蝶閥、球型閥、閘閥、安全閥等等。
    而氣動「閥」最常見的就是球塞閥和蝶型閥
    ​

    那什麼是單動式氣缸？

    那什麼是單動式氣缸？
    以比較簡單方式來說，複動式氣缸分別以進氣口和出氣孔來做開關的動作，單動式氣缸則從單一進氣孔即可控制。
    如下圖所示
    單動式氣缸內部係利用「​彈簧」使活塞做回彈的動作，氣源壓力由單一氣孔輸入，當壓縮氣源進入到氣缸腔內，壓力使活塞分別向氣缸蓋兩端方向推去，此時於氣缸蓋內的彈簧受活塞擠壓處於壓縮狀態。而當氣源中斷，氣缸內無氣源壓力，彈簧不再受活塞擠壓而回彈，將活塞向氣缸軸心方向推回，以此作用取代進出氣孔的切換。
    ​
    所以一般情況下單動式氣缸的功能就是當氣源輸入時閥門開啟，而當氣源中斷時彈簧則復歸，自動將閥門關閉。
    ​
    ​依據工作需求的不同也可以裝配不同的配件
    例如電磁閥、三點組合、微動開關和閥門定位器等

    資訊｜氣動閥做動不正常的原因，快看看有沒有幫助到你！

    Read Now
     
    若您使用氣動閥門遇到故障或維修等問題，歡迎聯繫我們，寔黈將盡可能的提供協助。

    ​造成氣動閥故障的因素有很多，為了能讓您在第一時間發現、解決故障問題，以下由寔黈整理造成氣動閥故障的可能。
    氣缸
    • 氣源壓力過大或過小
    • 氣源管線扭曲、洩漏
    • 氣缸O環、密封件損壞
    • 氣缸與閥門型號規格不符
    • 進出氣孔有異物堵塞
    • 單動氣缸彈簧變形、斷裂
    • 氣缸內部潤滑不足
    閥門
    • 軸心偏心、受損
    • 蝶閥膠圈摩擦力過大
    • 閥門內部有雜質異物
    • 閥門與氣缸型號規格不符
    • 與氣缸裝配不確實
    • 閥門內部潤滑不足
    配件
    • 電氣配件正負極接反
    • 配件軸心不在氣缸工作軸線上
    • 管路銜接處氣體洩漏
    • 電磁閥電壓不正確
    • 電磁閥氣孔位置裝配錯誤
    • 電磁閥線圈燒壞受損
    • 空氣調理組(三點組合)未正確設置
    • 配件裝配造成阻力過大
    • 顯示型微動開關內部凸輪位移

    資訊｜氣動閥加裝電磁閥，使工作系統更有效率

    Read Now
     
    ​電磁閥是以電磁線圈通、斷電來控制空氣源與氣動執行器（以下稱氣缸）的配合，
    ​進而控制氣動閥門啟閉或改變流量及流向的目的，為電控系統與執行機構中重要的角色。
    ​
    電磁閥簡單來說就是氣動閥與空氣源之間的控制元件，以電力即可控制氣動執行器對應氣動閥的作動，讓你的流體運輸系統操作更加準確且距離不受限制。
    ​
    ​氣動閥為什麼還要加裝電磁閥？
    因自動化設備越來越廣泛，許多生產作業由電控系統控制
    操作人員於電控室即可同時控制多部機台以減少人力資源
    在高危險性或惡劣的環境遠端操作更可增加工作人員安全性
    ​五口二位電磁閥的構造是？
    五口二位電磁閥​通電時，閥芯受磁力影響而橫移壓縮彈簧，空氣壓力源（藍色部分）進入電磁閥後由B孔進入至氣缸內，氣缸內部空氣經由氣缸活塞推送由A孔排出（綠色部分）。如下圖所示。
    五口二位電磁閥斷電時，因磁力消失使彈簧推動閥芯回彈，空氣壓力源（藍色部分）進入電磁閥後由A孔輸入至氣缸內，氣缸內部空氣則改由B孔排出（綠色部分）。如下圖所示。
    ​電磁閥的功能及型式相當多，寔黈氣動執行器系列產品皆配合使用五口二位電磁閥，與三點組合一同使用更可以有效增加電磁閥及氣缸壽命。

    資訊｜閥門種類分不清楚嗎？三分鐘讓你認識五種常見的閥門

    Read Now
     
    閥門為流體運輸系統中重要的調節裝置，基本可控制流體的開關、流量和流向等功能。
    閥門的種類及規格繁多，不同的工作環境和工作需求所使用的閥門也不相同，
    ​以下說明5種常見閥類的工作原理及優缺點。
    ​
    • 球閥（Ball valve）
    又稱球塞閥，為一種常見的主要閥類，是由塞閥改良而來，以球體取代柱塞。球體設有一貫穿孔，旋轉球體可控制貫穿孔與流道的配合以調整閥門啟閉。閥座可依工作條件選用適合的材質，​因密封性佳且構造簡單易於操作及維修而廣泛運用。
    優點：
    • 密封性高
    • 直通流道阻力小
    • 口徑尺寸多樣，配合範圍廣
    • 可作多孔應用，例如三通球閥
    缺點：
    • 金屬球體製造成本較高
    • 流體含雜質或顆粒較大時，球體和閥座易受損
    • 球型閥（Globe valve）
    因外形似球而稱之，以閥板與閥座之配合開啟或關閉流道，常用於截斷及節流。閥體內流道呈S型，流體經過時將改變流向，使阻力增加故流體壓力下降。
    優點：
    • 工作行程小，啟閉時間短
    • 流體截斷及流量控制能力佳
    • 密封面磨擦力小，耐用度高
    缺點：
    • 流體壓力因阻力而降低
    • 閥門操作時需要較大的力
    • 不適用含沉澱物及黏性流體
    • 閘閥（Gate valve）
    ​利用閥桿帶動閘板做直線運動，以閘板升降開啟或關閉流道。閘板半開使用時，流體衝擊閘板易造成閥座震動而損傷，故不適合節流使用，僅適用全開或全關場合。
    優點：
    • 兩端面之間距離較短
    • 直通流道阻力小
    • 流體與閘板呈垂直，啟閉所需的力較小
    缺點：
    • 僅適用於全開或全關之場合
    • 閘板行程高，操作時上方所需空間較大
    • ​開啟和關閉所需時間較長
    • 止回閥（Check valve）
    又稱逆止閥、單向閥，顧名思義僅允許流體單向流通，一方向流體壓力作用下，即閥瓣開啟使流道暢通；反之，當另一方向流體壓力作用時，閥瓣即關閉達到防止倒流之效果。
    優點：
    • 構造簡單，易於操作及維修
    • ​防止流體倒流，保持單向流動
    缺點：
    • 安裝時須注意流體方向
    • 若壓力過小可能影響截斷能力
    • 瞬間啟閉可能使閥瓣撞擊受損
    • 蝶閥（Butterfly valve）
    又稱蝶型閥，控制閥板旋轉角度即可調整啟閉及流量。蝶閥可分為彈性密封及金屬直接密封，彈性密封是利用膠圈防漏​，低壓密封性好，但膠圈有溫度及壓力上的限制；金屬直接密封是以金屬面直接接觸，工作溫度範圍較廣。
    ​
    參考連結 - 球閥球墊、閥座、蝶閥交圈材質選用參考
    優點：
    • 構造簡單且安裝方便
    • 體積和重量皆小於其他同口徑閥門
    • 流通口徑大，阻力小
    缺點：
    • 流通口徑大，不適用小流量控制
    • 密封膠圈易受工作溫度及壓力影響

    資訊｜為什麼要加裝三點組合？維持、穩固你的生產效率

    Read Now
     
    通常在氣壓設備系統中空壓機輸出端會加裝三點組合，而客戶指定氣缸加裝電磁閥時，我們也會建議使用者加裝三點組合。

    ​當空氣從空壓機等設備輸出時，壓縮空氣中含有雜質、水氣及油份，若沒安裝三點組合可能會使管路及氣缸等空氣流經過部分生鏽、氧化甚至​​磨損。
    三點組合又稱為空氣調理組其功能為：
    ．過濾：空氣濾清
    ．調壓：調整壓力
    ．給油：給予潤滑
    • 過濾：空氣濾清
    作動原理為利用內部葉片旋轉造成離心力，分離壓縮空氣中的水氣及雜質微粒並聚集在杯底，壓縮空氣則經濾網由出口排出。若空氣未先過濾可能影響其後續部分，所以過濾器必須裝在第一個位置。
    ​
    • 調壓：調整壓力
    調整壓縮空氣減壓至工作壓力後輸出，壓力表可讀輸出之壓力大小。壓力調整只能減壓無法加壓。假設輸入壓力為5bar，則調整後輸出壓力僅能低於5bar，無法高於輸入壓力。
    ​
    • 給油：給予潤滑
    利用文氏管原理將油杯內的潤滑油和空氣混合，混合後成油霧狀輸出，使管路、電磁閥等等相關配件及氣缸內部零件潤滑，維持其功能及延長使用壽命。

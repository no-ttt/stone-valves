# SEO 惡補筆記

> 給第一次認真碰 SEO 的人：先建立觀念，再知道該做什麼、不用做什麼。範例都以寔黈企業（閥門 B2B 官網）為主。
> 實作細節請看同資料夾的 [SEO-NextJS.md](./SEO-NextJS.md)。

---

## 0. 一句話理解 SEO

**SEO（Search Engine Optimization，搜尋引擎最佳化）＝讓「正在找你產品的人」在 Google 上找到你。**

這件事可以拆成三步：

```
Google 找得到你（爬取） → Google 看得懂你（索引） → Google 覺得你最好（排名）
```

任何一步卡住，後面的步驟都不會發生。

---

## 1. 搜尋引擎怎麼運作

| 階段 | Google 在做什麼 | 你要確保的事 |
|---|---|---|
| **爬取 Crawl** | Googlebot 順著連結和 sitemap 逛網站 | 頁面有連結可以到達、`robots.txt` 沒有擋住、伺服器不會掛掉 |
| **索引 Index** | 解析 HTML，理解頁面在講什麼，存進資料庫 | 內容是文字（不是圖片）、沒有 `noindex`、沒有大量重複頁面 |
| **排名 Rank** | 使用者搜尋時，從索引中挑出最相關、最可信的結果 | 內容符合搜尋意圖、有權威性、網站速度快、手機好用 |

**常見誤會**：網站上線不代表 Google 會收錄。新網站通常要幾天到幾週，到 Search Console 提交 sitemap 可以加快速度。

## 2. 關鍵字與搜尋意圖

### 2.1 關鍵字的種類

| 類型 | 例子 | 搜尋量 | 競爭 | 轉換率 |
|---|---|---|---|---|
| 大詞（短尾） | 閥門 | 高 | 極高 | 低 |
| 中詞 | 氣動球閥 | 中 | 中 | 中 |
| 長尾詞 | 不鏽鋼法蘭氣動球閥 2 吋 | 低 | 低 | **高** |

**中小企業的策略：先吃長尾詞與中詞。** 搜尋「法蘭氣動球閥 規格」的人，比搜尋「閥門」的人更接近下單。

### 2.2 搜尋意圖（Search Intent）——比關鍵字本身更重要

| 意圖 | 使用者想要 | 例子 | 對應頁面 |
|---|---|---|---|
| 資訊型 | 學東西 | 「什麼是氣動執行器」「球閥蝶閥差異」 | `/info` 文章 |
| 導航型 | 找特定網站 | 「寔黈」「stone valves」 | 首頁 |
| 商業調查型 | 比較、評估 | 「氣動閥 推薦」「台灣氣動閥廠商」 | 產品分類頁、關於我們 |
| 交易型 | 準備購買或詢價 | 「氣動球閥 報價」 | 產品頁＋詢價表單 |

**判斷意圖的方法：直接去 Google 搜尋那個詞，看前 10 名是什麼類型的頁面。** 如果前 10 名都是文章，你拿產品頁去搶就很難排上去。

### 2.3 找關鍵字的工具

- **Google 自動完成**、搜尋結果底部的「相關搜尋」、「其他人也問了」：免費，而且是最真實的資料
- **Google Search Console**：上線後最有價值，它會告訴你使用者實際搜尋了哪些詞找到你
- **Google Keyword Planner**：需要有 Google Ads 帳號，能看到大概的搜尋量
- **Ahrefs、Semrush、Ubersuggest**：付費，可以看競爭對手排名的關鍵字

### 2.4 關鍵字蠶食（Keyword Cannibalization）

如果兩個頁面都在搶「氣動球閥」這個詞，Google 不知道該排哪一頁，結果兩頁都排不好。**每個關鍵字只指定一個主要頁面負責。**

## 3. 站內 SEO（On-Page）

### 3.1 一定要做好的標籤

| 元素 | 作用 | 怎麼寫 |
|---|---|---|
| `<title>` | 搜尋結果的藍色大標題，**排名影響最大的單一標籤** | 主關鍵字放前面，約 30 個中文字內，每頁都不一樣。例：`氣動球閥．球塞閥｜寔黈企業 STONE VALVES` |
| `meta description` | 搜尋結果標題下方的灰色說明 | 不直接影響排名，但會影響點擊率；70–160 字，寫清楚「你有什麼、為什麼選你」 |
| `<h1>` | 頁面主標題 | 每頁只有一個，內容和 title 呼應 |
| `<h2>`～`<h3>` | 段落標題 | 依層級使用，不要因為想要字比較大就亂用 |
| 圖片 `alt` | 描述圖片，讓 Google 和視障者讀得懂 | 描述圖片內容，例如 `alt="不鏽鋼法蘭口氣動球閥"`，不要塞滿關鍵字 |
| URL | 網址 | 短、可讀、包含關鍵字：`/products/ball-valve` 優於 `/p?id=123` |

### 3.2 已經沒用（或用處很小）的東西

- `meta keywords`：Google 從 2009 年起就完全不看了
- 關鍵字密度：「關鍵字要出現 3%」是過時觀念，自然寫作就好
- 在頁面底部塞一堆關鍵字：會被判定為垃圾內容

### 3.3 內部連結

- 讓重要頁面拿到比較多連結，例如首頁連到 9 個產品分類
- 連結文字（anchor text）要有意義：寫「查看氣動球閥規格」，不要寫「點這裡」
- 文章裡提到產品時，順手連到產品頁
- 麵包屑導覽（首頁 › 產品資訊 › 球閥）同時對使用者和 Google 都有幫助

## 4. 技術 SEO（Technical）

| 項目 | 白話解釋 |
|---|---|
| **sitemap.xml** | 給 Google 的網站地圖，列出所有你希望被收錄的頁面 |
| **robots.txt** | 告訴爬蟲哪些路徑不要逛，例如 `/admin`。注意：它不能防止頁面被收錄，要防止收錄得用 `noindex` |
| **canonical** | 「這頁的正版網址是這個」。用來處理同一內容有多個網址的情況，例如帶參數的網址、http 和 https 兩種版本 |
| **noindex** | 「這頁不要放進搜尋結果」。用在感謝頁、測試頁、後台頁面 |
| **301 轉址** | 永久搬家，會把舊網址累積的排名權重轉給新網址。**改版時最重要的事** |
| **302 轉址** | 暫時搬家，權重不會轉移，改版時不要用 |
| **404** | 頁面不存在。少量無妨，但有被外部連結的舊網址要做 301 |
| **HTTPS** | 排名的基本門檻 |
| **行動版優先索引** | Google 以手機版內容為準，手機版缺的內容等於不存在 |
| **結構化資料（Schema / JSON-LD）** | 用機器看得懂的格式告訴 Google「這是產品」「這是公司」「這是麵包屑」，有機會在搜尋結果出現更豐富的顯示 |
| **SSR／SSG** | 伺服器直接輸出完整 HTML。純前端渲染（CSR）的內容，Google 雖然能看到，但比較慢也比較不穩。Next.js 預設就幫你處理好了 |

### Core Web Vitals（網頁體驗指標）

| 指標 | 量測什麼 | 好的標準 | 常見原因 |
|---|---|---|---|
| **LCP** 最大內容繪製 | 主要內容多快出現 | ≤ 2.5 秒 | 首屏大圖太重、伺服器慢 |
| **INP** 互動延遲 | 點擊後多快有反應 | ≤ 200 毫秒 | JavaScript 太多太重 |
| **CLS** 版面位移 | 畫面會不會亂跳 | ≤ 0.1 | 圖片沒設尺寸、字型晚載入 |

這些指標影響排名的比重不大，但會影響使用者會不會留下來。可以用 [PageSpeed Insights](https://pagespeed.web.dev/) 檢查。

## 5. 內容與 E-E-A-T

Google 評估內容品質的框架：

- **Experience 經驗**：有沒有實際做過、用過？→ 放實際的安裝案例、工廠照片
- **Expertise 專業**：懂不懂這個領域？→ 規格表、選型建議、技術文章
- **Authoritativeness 權威**：業界認不認可你？→ 認證、客戶名單、被其他網站引用
- **Trustworthiness 可信**：可不可以相信你？→ 公司地址、電話、統編、ISO／CE 證書

**對寔黈來說，最有效的內容是：**

1. 產品分類頁補上**文字**：適用產業、材質、口徑、壓力等級、規格表
2. 「選型問答」類的文章：
   - 氣動球閥和電動球閥怎麼選？
   - 單動和雙動執行器的差別
   - 法蘭口、牙口、焊口球閥各適合什麼場合
   - 閥門漏氣的常見原因與處理
3. 實際的案例分享：某產業的某條產線用了哪些閥門、解決了什麼問題

**原則：回答客戶實際會問的問題。** 業務每天被問什麼，就寫什麼。

## 6. 站外 SEO（Off-Page）

**反向連結（Backlink）**：其他網站連到你的網站，等於幫你投一票。重點是品質，不是數量。

| 好的連結來源 | 要避免的 |
|---|---|
| 產業公會、協會的會員名錄 | 花錢買連結 |
| 經銷商、合作夥伴的官網 | 大量的論壇簽名檔、留言連結 |
| 產業媒體報導、展覽參展名單 | 連結農場、PBN（私人部落格網路） |
| 台灣經貿網、工業採購平台 | 和你產業完全無關的網站 |

**B2B 製造業的實際做法**：請經銷商在官網放上你的連結；參展時確認主辦單位的參展商頁面有連到你的官網；在採購平台建立公司檔案。

## 7. 在地 SEO（Local SEO）

客戶搜尋「台中 氣動閥」這類帶地區的詞時，結果上方會出現地圖區塊。要出現在這裡：

1. 申請並驗證 **Google 商家檔案**（Google Business Profile）
2. **NAP 一致**：公司名稱（Name）、地址（Address）、電話（Phone）在官網、商家檔案、各平台都要寫得一模一樣
3. 上傳工廠和產品照片、填寫營業時間
4. 請合作客戶留下 Google 評論

## 8. 衡量成效

### 必裝工具

| 工具 | 用途 |
|---|---|
| **Google Search Console** | SEO 最重要的工具：看哪些關鍵字帶來曝光和點擊、哪些頁面沒被收錄、有沒有錯誤 |
| **Google Analytics 4** | 看使用者進站後的行為：停留多久、有沒有填詢價表單 |
| **PageSpeed Insights** | 檢查網站速度 |
| **Rich Results Test** | 檢查結構化資料有沒有寫對 |

### Search Console 的四個核心數字

- **曝光次數**：出現在搜尋結果幾次
- **點擊次數**：被點了幾次
- **CTR 點擊率**：點擊 ÷ 曝光。曝光高但點擊率低，表示 title 或 description 不吸引人
- **平均排名**：排在第 11–20 名的關鍵字最值得優化，稍微加強就有機會擠進第一頁

### 真正要看的 KPI

對 B2B 官網來說，**詢價數量**比流量更重要。在 GA4 把「送出詢價表單」「點擊電話」「點擊 Email」設成轉換事件。

## 9. 時間預期

| 時間 | 會看到什麼 |
|---|---|
| 上線 1–4 週 | 頁面陸續被收錄，品牌詞（「寔黈」）開始有排名 |
| 1–3 個月 | 長尾詞開始出現在 Search Console |
| 3–6 個月 | 中詞的排名開始穩定，流量明顯成長 |
| 6–12 個月 | 持續產出內容的話，競爭詞也有機會排上來 |

**SEO 是複利，不是開關。** 改版後的前幾週排名可能會先震盪，這是正常的。

## 10. 常見迷思

| 迷思 | 事實 |
|---|---|
| 「做一次就好」 | 需要持續產出內容、修正問題 |
| 「關鍵字越多越好」 | 塞關鍵字會被懲罰，一頁專注一個主題 |
| 「買 Google 廣告會提升自然排名」 | 兩者完全獨立 |
| 「提交 sitemap 就保證收錄」 | sitemap 只是建議，品質太差的頁面一樣不會被收錄 |
| 「AI 寫的內容會被懲罰」 | Google 看的是品質和有沒有幫助，不是誰寫的；但大量產出的空洞內容會被判為低品質 |
| 「改版沒關係，排名會自己回來」 | 沒做 301 轉址的話，舊排名會直接消失 |
| 「SEO 有保證第一名的方法」 | 沒有，宣稱保證排名的廠商要小心 |

## 11. AI 搜尋時代補充（GEO／AEO）

Google AI Overviews、ChatGPT、Perplexity 這類 AI 搜尋會直接摘要答案。要讓 AI 引用你：

- 內容結構清楚：用標題、清單、表格，**開頭第一段就直接回答問題**
- 提供明確的事實和數字：口徑範圍、壓力等級、材質、認證
- 加上結構化資料
- 品牌在其他網站（媒體、平台、論壇）被提及的次數越多，AI 越容易認得你

基本功和傳統 SEO 是一樣的：把內容寫清楚、寫正確、讓網站有可信度。

## 12. 名詞速查

| 名詞 | 意思 |
|---|---|
| SERP | 搜尋結果頁（Search Engine Results Page） |
| 自然流量 Organic | 不是透過廣告、從搜尋結果點進來的流量 |
| SEM | 搜尋引擎行銷，通常指付費關鍵字廣告 |
| Anchor Text | 連結上面的文字 |
| Crawl Budget | Google 願意花多少資源爬你的網站（小網站不用擔心） |
| Domain Authority | 第三方工具估算的網域權威分數，不是 Google 的官方指標 |
| Featured Snippet | 精選摘要，出現在搜尋結果最上方的答案框 |
| Long-tail | 長尾關鍵字 |
| Slug | 網址最後那一段，例如 `ball-valve` |
| Thin Content | 內容太少、沒價值的頁面 |
| Duplicate Content | 重複內容 |
| Orphan Page | 孤兒頁面，沒有任何內部連結指向它的頁面 |

## 給你的 TL;DR

1. **先確保 Google 找得到、看得懂**：sitemap、301 轉址、每頁有獨特的 title 和 description、內容用文字呈現
2. **一頁一個主題**：產品分類頁對應產品關鍵字，文章對應客戶的問題
3. **持續寫客戶會問的問題**：每月 1–2 篇
4. **建立可信度**：認證、地址電話、案例、經銷商和平台的連結
5. **每月看一次 Search Console**：找排名 11–20 名的關鍵字加強，找點擊率低的頁面改標題
